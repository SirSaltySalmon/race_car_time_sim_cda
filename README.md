# Race Car Simulator

Input CdA, mass, and accuracy of simulator to get estimated time for a model race car to run. Made to assist Chimera Racing with modelling times and speeds for a given design.

Models the drag, mass, and force with functions within solver.py. Considers mass decreasing as gas from canister depletes to accurately model velocity and displacement.

### Chimera Racing placed 4th in the 2025-26 STEM Racing Regional Finals using this model. Team members reports an accuracy to 0.01 seconds.

Teams are welcomed to fork and adjust formulas to model their own cars. Code is commented and only solver.py needs to be modified.
